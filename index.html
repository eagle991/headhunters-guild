⚙ ИСТОЧНИК ДАННЫХ

📌 Как подключить:

1. Открой свою Google Таблицу "HeadHunters — База данных"

2. Нажми «Файл» → «Поделиться» → «Опубликовать в интернете» (или сделай доступ "Все, у кого есть ссылка")

3. Скопируй ID из адресной строки: docs.google.com/spreadsheets/d/ЭТОТ_ID/edit

4. Вставь ID выше и нажми «Сохранить»

⚠ Важно: названия листов должны точно совпадать: Пользователи, Игроки_норма, Аукцион, Очереди, Очередь_Участники, DKP_Баланс, DKP_История, Мероприятия, Посещения, Статистика_лута, Активность
